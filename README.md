#  Reel Insights – TMDB Movie Industry Analysis

## Project Overview

Reel Insights is an end-to-end data analytics project that explores approximately 2,500 movies using TMDB data. The project uses Python, Pandas, SQL, and data visualization to understand movie performance, audience preferences, genre trends, and box-office revenue.

The project transforms raw movie datasets into meaningful business insights through data cleaning, relational database management, exploratory data analysis, and an interactive Streamlit dashboard.
